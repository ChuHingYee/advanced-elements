**做了什么**

**关键结论（踩坑后确认的事实）**
- ElTableV2 虚拟网格 SSR 渲染不出行，客户端补渲染必报 hydration mismatch → 预览必须 ClientOnly。
- AdvTable 实例 id 默认随机生成；要用列状态持久化必须显式给 `storageKey`（或固定 `uiConfig.tableId`）。
- 选择列**不会**自动注入，必须在 `columns` 里写 `{ selection: true }`；`rowConfig.rowSelection` 只管行为。
- `valueEnum` 不配 `valueType: 'select'` 不参与渲染（只显示原始值）。
- `pagination.mode: 'manual'` 下表格**不会**调用 `request.source`，只派发 `pageChange`；本地数据追加要自己传 `total`（否则第一页就判 hasMore=false）。
- 实例 API 里**没有** `autoSize()`，自动列宽只有 `columnConfig.autoSizeColumns`；`RowPinConfig` 也没有 `topRowHeight/bottomRowHeight`（旧文档写错了，已顺手纠正）。
- 旧 md 示例里 `search.fields[].type: 'daterange'` 不成立，内置只有 `input/select/datePicker/switch/number`。
